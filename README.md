# نظام تقدير السكان بـ ARIMA

تطبيق ويب محلي بـ FastAPI لتقدير أعداد السكان باستخدام نموذج ARIMA مع واجهة محادثة موجّهة.

## التثبيت والتشغيل

```bash
# 1. إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate      # Linux/Mac
# venv\Scripts\activate       # Windows

# 2. تثبيت المتطلبات
pip install -r requirements.txt

# 3. إنشاء بيانات تجريبية
python create_sample.py

# 4. تشغيل الخادم
uvicorn app.main:app --reload --port 8000
```

افتح المتصفح على: http://127.0.0.1:8000

## الاستخدام

1. ارفع ملف `sample_data.xlsx` (أو ملفك الخاص بنفس المخطط)
2. اكتب سؤالًا مثل: «ما عدد السكان المتوقع في عام 2030؟»
3. اختر المحافظة ← المنطقة ← الحي ← الفئة العمرية
4. شاهد الرسم التفاعلي وجدول النتائج

## تشغيل الاختبارات

```bash
pytest tests/ -v
```

## تشغيل VS Code

افتح المجلد `population-arima` في VS Code واضغط F5.

## مخطط البيانات

| العمود | النوع | مثال |
|---|---|---|
| السنة | عدد صحيح | 2015..2024 |
| المحافظة | نص | عمّان |
| المنطقة | نص | قصبة عمّان |
| الحي | نص | جبل الحسين |
| الفئة العمرية | نص | 0-4 |
